# 智达补习中心 - 真实数据库交互系统 (SS2 & SS15)

这是一个**真正具备后端逻辑与 SQLite 数据库持久化**的完整 Web 应用系统。绝无硬编码静态数据，任何电脑运行后，家长填写的表单都将真实写入数据库，教务管理后台可实时查询、按分店过滤并进行批准操作。

---

## 🛠️ 项目特色与架构设计

1. **真实 SQLite 数据库 (`tutoring.db`)**：
   - 使用 SQL 语句建立 `inquiries` 咨询表。
   - 所有家长数据（姓名、电话、分店、年龄、提问、AI 分类、AI 拟稿、状态）均持久化落盘，不会因为刷新网页或关机而丢失。

2. **数据安全与隔离（家长看前台，老师看后台）**：
   - **家长入口 (`http://127.0.0.1:5000`)**：只允许输入信息和查看 FAQ，绝对无法查看到其他家长的私人电话或后台数据库。
   - **教务后台 (`http://127.0.0.1:5000/admin`)**：具备查看总咨询数、筛选 SS2/SS15 分店、查看 AI 分类与自动拟稿、处理需要人工介入的单子等功能。

3. **智能 FAQ 回复 & 严谨防编造逻辑**：
   - 包含算法规则，对 `收费`、`时间`、`课程` 进行自动分类。
   - 严格限定仅使用提供的 9 条 FAQ 规则进行起草。遇到任何 FAQ 未提及的问题（如折扣、教师姓名、路线导航），自动标注为 `需要人工`。

## 🚀 如何在任何电脑上运行

### 步骤 1：解压 zip 包
在电脑上解压 `tutoring_system_dynamic.zip`。

### 步骤 2：安装 Flask 依赖
打开 Terminal（终端）或 CMD，进入解压出来的文件夹，运行：
```bash
pip install flask
```

### 步骤 3：一键启动服务器
运行命令：
```bash
python app.py
```
（系统会自动检测并执行 `init_db.py` 建立数据库与初始测试数据）

### 步骤 4：体验交互
1. 打开浏览器进入 **家长前台**：`http://127.0.0.1:5002`
   - 尝试填写一条真实数据（如：“姓名：李妈妈，电话：012-9998888，分店：SS2，年龄：10，问题：请问试课要钱吗？支持现金缴费吗？”）并提交。
2. 打开浏览器进入 **教务后台**：`http://127.0.0.1:5002/admin`
   - 刷新或查看刚才提交的订单，体验实时按 SS2/SS15 分店筛选以及点击【批准回复】按钮！
